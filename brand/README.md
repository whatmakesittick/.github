# Brand

The mark is a tick whose short arm starts on a crank wheel: the wheel turns and
the tick lands. The tick is a drawn, tapered shape rather than an even stroke.

## Files

| File | What it is |
| --- | --- |
| `mark.svg` | The mark alone for dark grounds, 64 × 64, transparent. |
| `mark-light.svg` | The mark alone for light grounds. |
| `favicon.svg` | Site icon: the amber mark on a rounded graphite square, 32 × 32. |
| `lockup-horizontal.svg` | Mark and wordmark side by side, for dark grounds. |
| `lockup-horizontal-light.svg` | Mark and wordmark side by side, for light grounds. |
| `lockup-stacked.svg` | Mark above the wordmark, for dark grounds. |
| `avatar-512.png` | GitHub organisation avatar, 512 × 512. |
| `readme-hero.png` | Banner for the top of the readmes, 1280 × 640 at double density. |
| `social-card.png` | Link preview, 1200 × 630. |

The lockup text is converted to outlines, so the lockups need no font. They are
cropped tight, so add the clear space below when you place them.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Graphite | `#0b0d10` | Dark ground |
| Text | `#e6e9ee` | Text on dark |
| Prose | `#c3c9d2` | Body copy on dark |
| Muted | `#8b929c` | Secondary text on dark |
| Amber | `#f5a524` | The mark and the word "tick" on dark |
| Paper | `#f4f2ec` | Light ground |
| Ink | `#14161a` | Text, wheel and hub on light |
| Deep amber | `#c9821a` | The tick on light |
| Amber text | `#b8731a` | The word "tick" on light |

## Type

- Wordmark: Inter SemiBold (600), letter spacing −0.03em, with "tick" in amber.
- Headlines in the banner and the link preview: Inter Bold (700), −0.035em.
- Small details such as the address: JetBrains Mono Medium (500).

## Clear space

Leave empty space around the mark at least as wide as the wheel's diameter (the
outer edge of the ring, 20 of the mark's 64 units). In a lockup, measure it from
the outer edge of both the mark and the wordmark.

## Minimum size

- Favicon: 16 px.
- The mark anywhere else: 24 px.

## Dark and light

- On graphite or other dark grounds, use `mark.svg` and the lockups without a
  suffix: an all-amber mark with light text.
- On paper or other light grounds, use the `-light` files: an ink wheel and hub,
  a deep amber tick and ink text.
- On photos or busy grounds, put the mark on a graphite panel, as in the
  favicon.

## Do not

- Recolour the mark or the wordmark with colours outside this palette.
- Rotate or tilt the mark. The tick always rises to the right.
- Stretch or squash the mark. Scale it evenly.
